Warm, fresh, food-focused, and approachable. The design should feel like a modern healthy-food brand rather than a hospital or clinical dashboard.

5. Key UX Principles

Show one primary action per screen.

Make nutrition values scannable rather than burying them in paragraphs.

Always show the user's context when recommending a food or pack.

Use progressive disclosure for detailed nutrient information.

Make substitutions easy and show their nutrition/price impact.

Clearly distinguish estimates, recommendations, and factual product data.

Never hide demo-payment status.

6. Dashboard Layout

Header → greeting/profile → daily calorie summary → macro/micro progress → recommended foods → Calin Pack card → recent meals/scans → AI shortcut.

7. Food Card

Image → food name → key nutrition values → nutrient tags → price → buttons for details and add. Cards should support comparison and filters.

8. Calin Pack UX

Start with the user's nutrition summary, then show three tier cards. Selecting a tier opens the generated pack. Each item can be replaced. Changes should update nutrition totals and price immediately.
